# NexaBytes

A modern React + Vite application deployed live on GitHub Pages.

🌐 **Live Website:** https://dani1218.github.io/NexaBytes1/

## Project Setup

This project uses:
- **React** - UI library
- **Vite** - Build tool and dev server
- **GitHub Pages** - Hosting

## Development

### Install Dependencies
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

### Deploy to GitHub Pages
```bash
npm run deploy
```

## Technology Stack

- React (Latest)
- Vite v8.2.0
- ESLint for code quality
- Automated deployment via gh-pages
